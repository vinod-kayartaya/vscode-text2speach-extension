# VS Code Text to Speech

A simple extension to read selected text out loud.

## Features

- Read selected text using system text-to-speech
- Supports Windows, macOS, and Linux

## Usage

1. Select text in any editor
2. Open Command Palette (Ctrl+Shift+P)
3. Type "Read Selected Text" and press Enter

## Requirements

- Windows: No additional requirements
- macOS: No additional requirements
- Linux: Requires `espeak` (`sudo apt-get install espeak`)
